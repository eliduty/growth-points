# Nuxt App 项目规则

## 约定

- 使用开发时优先有用对应技术的skill进行开发。
- 组件优先使用 Vue 3 SFC 组合式 API 风格，代码控制在 200 行以内，保持单一职责。
- 使用有意义的变量名和函数名，命名要简单、专业，避免无意义的缩写（除非是广泛认可的）。
- 生成代码时添加简洁、专业注释，有注释时需保持注释与代码一致，不得随意删除已有注释。
- 当生成的代码超过 20 行时，优先考虑是否可以进行适当的抽象或聚合。
- 优先使用 UnoCSS，禁止写原生 CSS（除非必要）。
- 组件优先使用 Vue 3 SFC 组合式 API 风格，代码控制在 200 行以内，保持单一职责。
- 优先使用 Typescript 和 ESM 模块，利用接口和类型别名增强代码可读性，避免使用 `any` 类型。
- 优先使用 CSS 变量，实现主题系统支持品牌定制，建立统一的样式变量和工具类，处理 CSS 兼容性问题。
- 合理使用 computed/watch避免不必要的重渲染。
- 对用户输入进行转义和过滤，避免 XSS 攻击。
- 非必要不用Store，只在必要时使用。
