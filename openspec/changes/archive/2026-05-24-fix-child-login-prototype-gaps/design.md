## Context

孩子端登录页（`src/app/child/login/page.tsx` 和 `src/components/child/ChildLoginForm.tsx`）的实现与原型设计（`docs/prototypes/child-login.html`）存在视觉差异。原型设计定义了精确的尺寸、位置和动画效果，实际实现使用了近似值导致视觉效果偏离设计预期。

## Goals / Non-Goals

**Goals:**
- 修正装饰星星位置：从页面背景移至卡片内部四角
- 修正各项圆角和尺寸值以匹配原型
- 保持现有功能逻辑不变，仅调整样式

**Non-Goals:**
- 不修改登录逻辑或表单验证
- 不添加新功能
- 不重构代码结构

## Decisions

### 1. 装饰星星位置调整

**决策**: 将星星从页面背景（绝对定位百分比）移至卡片容器内部的四角位置。

**原因**: 原型设计中星星是卡片内部的装饰元素，与卡片一起移动。当前实现将星星放在页面背景上，破坏了视觉一致性。

**实现方式**:
- 在卡片容器（`.login-container`）内添加四个星星元素
- 使用绝对定位：`top: 16px, left/right: 20px` 和 `bottom: 80px, left/right: 12px`

### 2. 尺寸值修正

使用 Tailwind CSS 的任意值语法来精确匹配原型：

| 元素 | 原型值 | Tailwind 实现 |
|------|--------|--------------|
| 卡片圆角 | 28px | `rounded-[28px]` |
| 卡片内边距 | 40px 28px | `py-10 px-7` |
| 输入框圆角 | 14px | `rounded-[14px]` |
| 按钮圆角 | 14px | `rounded-[14px]` |
| 底部装饰条 | 10px | `h-[10px]` |

### 3. 星星颜色和动画

**决策**: 使用固定颜色值 `#FFD93D`（金色）而非 CSS 变量。

**原因**: 原型使用固定颜色，星星是装饰元素不应随主题变化。

## Risks / Trade-offs

- **Tailwind 任意值增加代码复杂度**: 使用精确值替代 Tailwind 默认值，增加了代码的可读性负担 → 可接受，因为这是设计还原的必要代价
- **星星动画可能与现有动画冲突**: 需确保 `twinkle` 动画定义不冲突 → 在 globals.css 中检查现有动画定义
