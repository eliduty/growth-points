# 技术文档

## 用户角色

### 家长（PARENT）

- 创建和删除任务
- 创建和删除礼物
- 设置兑换日（支持多选）
- 查看本周任务完成统计表
- 撤销孩子当天的任务完成记录
- 查看所有用户的积分信息

### 孩子（CHILD）

- 查看每日任务列表
- 完成任务获得积分
- 查看自己的积分余额
- 查看兑换日倒计时
- 在兑换日用积分兑换礼物
- 查看本周自己的完成情况

## API 接口

### 用户相关

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/user` | 获取当前登录用户 |
| POST | `/api/user` | 注册新用户 |
| POST | `/api/user/login` | 用户登录 |
| POST | `/api/user/logout` | 用户登出 |
| GET | `/api/users` | 获取所有用户列表 |

### 任务相关

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/tasks` | 获取任务列表（含今日完成状态） |
| POST | `/api/tasks` | 创建新任务 |
| DELETE | `/api/tasks/[id]` | 删除任务 |
| POST | `/api/tasks/complete` | 完成任务 |
| GET | `/api/tasks/completions/weekly` | 获取本周完成记录 |
| POST | `/api/tasks/completions/[id]/revoke` | 撤销完成记录 |

### 礼物相关

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/gifts` | 获取礼物列表 |
| POST | `/api/gifts` | 创建新礼物 |
| DELETE | `/api/gifts/[id]` | 删除礼物 |
| POST | `/api/gifts/redeem` | 兑换礼物 |

### 设置相关

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/settings/redemption-day` | 获取兑换日设置 |
| POST | `/api/settings/redemption-day` | 保存兑换日设置 |

## 数据库模型

### User（用户）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (CUID) | 主键 |
| name | String | 用户名 |
| password | String | 密码（bcrypt 加密） |
| role | UserRole | 角色（PARENT / CHILD） |
| currentPoints | Int | 当前可用积分 |
| totalPoints | Int | 累计获得积分 |

### Task（任务）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (CUID) | 主键 |
| name | String | 任务名称 |
| points | Int | 奖励积分 |
| description | String? | 任务描述 |

### Gift（礼物）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (CUID) | 主键 |
| name | String | 礼物名称 |
| points | Int | 所需积分 |
| description | String? | 礼物描述 |
| image | String? | 礼物图片 |
| available | Boolean | 是否可用 |

### TaskCompletion（任务完成记录）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (CUID) | 主键 |
| userId | String | 用户 ID |
| taskId | String | 任务 ID |
| completedAt | DateTime | 完成时间 |
| revoked | Boolean | 是否已撤销 |
| revokedAt | DateTime? | 撤销时间 |

### GiftRedemption（礼物兑换记录）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (CUID) | 主键 |
| userId | String | 用户 ID |
| giftId | String | 礼物 ID |
| pointsSpent | Int | 消耗积分 |
| redeemedAt | DateTime | 兑换时间 |

### Setting（设置）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (CUID) | 主键 |
| key | String (唯一) | 设置键名 |
| value | String | 设置值 |

## 业务规则

### 任务完成

- 同一个任务每天只能完成一次（以北京时间 UTC+8 判断）
- 完成后立即获得积分，同时增加当前积分和累计积分
- 家长可以撤销当天的完成记录，撤销后扣除相应积分

### 礼物兑换

- 只能在家长设定的兑换日兑换
- 积分必须足够才能兑换
- 兑换后立即扣除当前积分，累计积分不变

### 兑换日

- 由家长设置，支持多选（如选择周五和周六）
- 使用北京时间判断当前是否为兑换日
