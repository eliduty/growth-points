# 家长端应用设计

## 1. 使用场景定位

### 1.1 频率分析

| 功能 | 使用频率 | 分析理由 |
|------|---------|---------|
| 查看统计 | 中高频 | 家长想了解孩子本周完成情况，可能每周几次查看 |
| 撤销操作 | 低频 | 孩子误完成或需要调整时才使用，不是每天都有 |
| 任务管理 | 低频 | 任务通常是固定的日常任务，设置后很少改动 |
| 礼物管理 | 低频 | 礼物列表相对固定，偶尔补充或更新 |
| 兑换日设置 | 极低频 | 设置一次后基本稳定 |
| 成员管理 | 极低频 | 添加新成员是一次性操作 |

### 1.2 核心场景

家长端是「移动端 + 查看为主 + 周期性管理调整」：
- 家长打开应用，主要是查看孩子本周进度
- 偶尔需要撤销孩子的误操作
- 定期（如周末）可能调整任务或补充礼物

### 1.3 设计原则

| 原则 | 说明 |
|------|------|
| 视觉轻量化 | 减少按钮密度，使用隐藏操作 |
| 呼吸感优先 | 增加卡片间距和页面留白 |
| 一屏一任务 | 每个页面聚焦单一功能 |
| 触摸友好 | 长按、滑动等手势操作 |

---

## 2. 页面结构

### 2.1 整体架构

家长端采用四页面结构，配合底部导航：

| 页面 | 定位 | 核心内容 |
|------|------|---------|
| 首页（统计页） | 高频查看 | 本周各孩子完成情况概览 + 记录详情入口 |
| 任务页 | 低频管理 | 任务列表 + 创建/隐藏编辑删除 |
| 礼物页 | 低频管理 | 礼物列表（标签页）+ 兑换记录（标签页） |
| 设置页 | 极低频管理 | 分组卡片 + 独立管理入口 |

**底部导航：**

```
[统计]  [任务]  [礼物]  [设置]
```

### 3.5 撤销完成记录交互

**触发方式：长按记录卡片（500ms）**

**视觉反馈：**
- 长按时卡片背景变为 `#F0F4FF`
- 卡片轻微缩放 `scale(0.98)`
- 500ms 后弹出底部菜单

**撤销菜单：**

```
┌─────────────────────────────┐
│                             │
│   阅读书籍                   │ ← 记录名称
│   5月21日 09:30             │
│                             │
│   ─────────────────────     │
│                             │
│   [撤销这条记录]             │ ← 撤销选项
│                             │
│   [取消]                     │
│                             │
└─────────────────────────────┘
```

**撤销确认框：**

```
┌─────────────────────────┐
│   确认撤销这条完成记录？   │
│                         │
│   任务：阅读书籍         │
│   将扣回：10 积分        │
│                         │
│   [取消]    [确认撤销]   │
└─────────────────────────┘
```

**撤销范围：** 本周内（周一至周日）的完成记录均可撤销

**积分不足时的处理：**

当孩子当前积分不足以扣回时，系统自动按时间顺序撤销待确认的兑换记录，返还积分后再撤销完成记录。

## 8. 撤销操作汇总

| 撤销类型 | 入口页面 | 触发方式 | 积分变化方向 | 记录范围 |
|---------|---------|---------|-------------|---------|
| 撤销完成记录 | 统计页-记录详情页 | 长按记录卡片 | 扣回积分 | 本周完成记录 |
| 撤销兑换记录 | 礼物页-兑换记录标签 | 点击撤销按钮 | 返还积分 | 仅待确认状态 |

**已确认的兑换记录不可撤销。**

**积分不足时自动关联撤销：** 撤销完成记录时若孩子积分不足，系统自动按时间顺序撤销待确认的兑换记录以返还积分。
