# 家庭积分兑换系统 - 需求说明书

## 1. 项目概述

### 1.1 项目名称
家庭积分兑换系统（Family Points Redemption System）

### 1.2 项目背景
这是一个面向家庭的教育激励应用，旨在通过积分机制激励孩子完成日常任务，并通过兑换礼物的形式给予正向反馈。家长可以设置任务和奖励规则，孩子通过完成任务积累积分，并在指定日期兑换心仪的礼物。

### 1.3 项目目标
- 建立透明的任务完成和积分奖励机制
- 培养孩子的责任感和时间管理能力
- 提供直观的进度可视化和统计功能
- 简化家长的管理操作流程

---

## 2. 用户角色

### 2.1 家长（PARENT）
**权限与功能：**
- 用户注册和登录
- 管理任务（创建、删除）
- 管理礼物（创建、删除）
- 设置兑换日（支持多选）
- 查看本周任务完成统计表
- 撤销孩子当天的任务完成记录
- 查看所有用户的积分信息

### 2.2 孩子（CHILD）
**权限与功能：**
- 用户注册和登录
- 查看每日任务列表
- 完成任务获得积分
- 查看自己的积分余额
- 查看兑换日倒计时
- 在兑换日用积分兑换礼物
- 查看本周自己的完成情况

## 3. 核心功能模块

### 3.1 用户认证系统

#### 3.1.1 用户注册
- **输入项：**
  - 用户名（必填）
  - 密码（必填，至少6位）
  - 确认密码（必填）
  - 角色选择（家长/孩子，必选）

- **验证规则：**
  - 用户名不能为空
  - 密码长度至少6位
  - 两次密码必须一致
  - 必须选择角色

- **处理流程：**
  1. 用户填写注册信息
  2. 客户端验证输入格式
  3. 发送注册请求到后端
  4. 后端验证并创建用户
  5. 密码使用 bcryptjs 加密存储
  6. 登录状态保存到 Cookie

#### 3.1.2 用户登录
- **登录流程：**
  1. 显示所有已注册用户列表
  2. 用户选择要登录的账号
  3. 输入密码
  4. 后端验证密码
  5. 登录成功后设置 Cookie
  6. 跳转到对应角色的主界面

- **显示信息：**
  - 用户名
  - 角色图标（家长用皇冠，孩子用用户图标）
  - 角色标签

#### 3.1.3 用户登出
- 清除浏览器 Cookie
- 返回登录界面
- 显示登出成功提示

---

### 3.2 任务管理系统

#### 3.2.1 创建任务（家长）
- **输入项：**
  - 任务名称（必填）
  - 任务积分（必填，数字）
  - 任务描述（可选）

- **界面：**
  - 任务管理对话框
  - 表单输入界面
  - 任务列表显示

- **任务信息：**
  - 任务ID（自动生成，CUID格式）
  - 任务名称
  - 奖励积分
  - 任务描述
  - 创建时间
  - 更新时间

#### 3.2.2 查看任务列表
- **家长端：**
  - 显示所有任务
  - 显示任务名称和积分
  - 显示删除按钮

- **孩子端：**
  - 显示所有任务
  - 显示任务名称和积分
  - 显示任务描述
  - 显示完成状态（今天是否已完成）
  - 显示完成按钮
  - 已完成的按钮显示绿色"已完成"状态

#### 3.2.3 完成任务（孩子）
- **业务规则：**
  - 同一个任务每天只能完成一次
  - 使用北京时间（UTC+8）判断"今天"
  - 完成后立即获得积分
  - 任务状态实时更新

- **完成流程：**
  1. 孩子点击"完成"按钮
  2. 后端检查今天是否已完成
  3. 未完成则创建完成记录
  4. 增加用户积分
  5. 更新任务完成状态
  6. 返回成功提示

#### 3.2.4 删除任务（家长）
- 删除前不需要确认
- 删除后任务不再显示
- 历史完成记录保留

---

### 3.3 礼物管理系统

#### 3.3.1 创建礼物（家长）
- **输入项：**
  - 礼物名称（必填）
  - 所需积分（必填，数字）
  - 礼物描述（可选）

- **礼物信息：**
  - 礼物ID（自动生成）
  - 礼物名称
  - 所需积分
  - 礼物描述
  - 是否可用（available）
  - 创建时间
  - 更新时间

#### 3.3.2 查看礼物列表
- **显示内容：**
  - 礼物名称
  - 所需积分
  - 礼物描述
  - 兑换按钮（孩子端）

#### 3.3.3 兑换礼物（孩子）
- **业务规则：**
  - 只能在设定的兑换日兑换
  - 积分必须足够
  - 兑换后立即扣除积分

- **兑换流程：**
  1. 孩子点击"兑换"按钮
  2. 后端验证是否为兑换日
  3. 验证积分是否足够
  4. 扣除对应积分
  5. 显示成功提示

#### 3.3.4 删除礼物（家长）
- 删除后礼物不再显示
- 已兑换的记录保留

---

### 3.4 兑换日管理系统 ⭐

#### 3.4.1 设置兑换日（家长）
- **功能描述：**
  - 家长可以设置每周哪些日子可以兑换礼物
  - 支持多选（例如：可以选择周五、周六）
  - 点击日期按钮切换选择状态

- **UI设计：**
  - 7个日期按钮（周日到周六）
  - 选中的日期显示为粉色高亮
  - 未选中的日期显示为空心
  - 下方显示当前设置的文字说明
  - "保存兑换日设置"按钮

- **存储格式：**
  - 数据库存储为逗号分隔的数字字符串
  - 例如："5,6" 表示周五和周六
  - 数字映射：0=周日, 1=周一, ..., 6=周六

- **API接口：**
  - GET `/api/settings/redemption-day` - 获取兑换日设置
  - POST `/api/settings/redemption-day` - 保存兑换日设置

#### 3.4.2 兑换日验证
- **验证规则：**
  - 使用北京时间（UTC+8）判断当前日期
  - 检查当前星期几是否在兑换日列表中
  - 如果在列表中，允许兑换
  - 如果不在，禁止兑换并提示

---

### 3.5 倒计时显示系统 ⭐

#### 3.5.1 显示位置
- 显示在孩子端积分卡片上
- 位于"累计获得"积分下方

#### 3.5.2 倒计时逻辑
- **在兑换期内：**
  - 显示："今天可兑换"
  - 显示："距离结束: HH:MM:SS"
  - 倒计时到当天 23:59:59

- **不在兑换期内：**
  - 显示："X天后兑换"
  - 显示："剩余 HH:MM:SS"
  - 倒计时到下一个兑换日的 00:00:00

#### 3.5.3 计算规则
- 使用北京时间（UTC+8）进行所有时间计算
- 每秒更新一次
- 自动计算距离下一个兑换日的天数

#### 3.5.4 时间格式
- 小时、分钟、秒都使用两位数显示（补零）
- 例如："06:05:32"

---

### 3.6 积分管理系统

#### 3.6.1 积分类型
- **当前积分：** 可用于兑换礼物的积分
- **累计积分：** 历史获得的总积分（不因兑换而减少）

#### 3.6.2 积分获取
- 完成任务后立即获得
- 积分数量由任务设置决定
- 记录完成时间和任务信息

#### 3.6.3 积分消耗
- 兑换礼物时扣除
- 扣除数量由礼物设置决定
- 积分不足时禁止兑换并提示

#### 3.6.4 积分显示
- 显示在顶部积分卡片
- 大字体显示当前积分
- 小字体显示累计积分

---

### 3.7 统计报表系统

#### 3.7.1 本周完成情况表
- **表格结构：**
  - 横向：周一到周日
  - 纵向：所有任务
  - 单元格：显示完成状态（绿色勾/灰色圈）
  - 底部：每天完成的任务数量

- **功能：**
  - 显示任务名称和积分
  - 显示每个任务每天的完成状态
  - 显示完成时间（悬停提示）
  - 显示每天获得的积分

- **家长额外功能：**
  - 每个完成记录旁边显示"撤销"按钮
  - 点击撤销可以取消当天的完成
  - 撤销后扣除相应积分

#### 3.7.2 撤销完成记录（家长）
- **业务规则：**
  - 只能撤销当天的完成记录
  - 撤销后扣除任务对应的积分
  - 完成记录标记为已撤销

- **撤销流程：**
  1. 家长点击撤销按钮
  2. 后端验证是否为今天
  3. 更新完成记录状态
  4. 扣除用户积分
  5. 刷新数据显示

## 5. 技术实现

### 5.1 技术栈
- **前端框架：** Next.js 16 (App Router)
- **编程语言：** TypeScript 5
- **样式方案：** Tailwind CSS 4
- **UI组件库：** shadcn/ui (New York 风格)
- **图标库：** Lucide React
- **数据库：** SQLite
- **ORM：** Prisma
- **认证：** 自定义 Cookie 认证
- **状态管理：** React Hooks
- **表单处理：** React Hook Form
- **密码加密：** bcryptjs

### 5.2 数据库设计

#### 5.2.1 User 表（用户表）
```prisma
model User {
  id           String   @id @default(cuid())
  name         String
  password     String
  role         Role     @default(CHILD)
  currentPoints Int     @default(0)
  totalPoints  Int     @default(0)
  createdAt    DateTime @default(now())
  updatedAt    DateTime @updatedAt
}

enum Role {
  PARENT
  CHILD
}
```

#### 5.2.2 Task 表（任务表）
```prisma
model Task {
  id          String    @id @default(cuid())
  name        String
  points      Int
  description String?
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt
}
```

#### 5.2.3 Gift 表（礼物表）
```prisma
model Gift {
  id          String    @id @default(cuid())
  name        String
  points      Int
  description String?
  image       String?
  available   Boolean   @default(true)
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt
}
```

#### 5.2.4 TaskCompletion 表（任务完成记录表）
```prisma
model TaskCompletion {
  id         String    @id @default(cuid())
  userId     String
  taskId     String
  completedAt DateTime
  revoked    Boolean   @default(false)
  revokedAt  DateTime?
  user       User      @relation(fields: [userId], references: [id])
  task       Task      @relation(fields: [taskId], references: [id])
}
```

#### 5.2.5 Setting 表（设置表）
```prisma
model Setting {
  id        String   @id @default(cuid())
  key       String   @unique
  value     String
  updatedAt DateTime @updatedAt
}
```

### 5.3 API 接口设计

#### 5.3.1 用户相关
- `GET /api/user` - 获取当前登录用户
- `POST /api/user` - 注册新用户
- `POST /api/user/login` - 用户登录
- `POST /api/user/logout` - 用户登出
- `GET /api/users` - 获取所有用户列表

#### 5.3.2 任务相关
- `GET /api/tasks` - 获取任务列表（包含今日完成状态）
- `POST /api/tasks` - 创建新任务
- `DELETE /api/tasks/[id]` - 删除任务
- `POST /api/tasks/complete` - 完成任务
- `GET /api/tasks/completions/weekly` - 获取本周完成记录
- `POST /api/tasks/completions/[id]/revoke` - 撤销完成记录

#### 5.3.3 礼物相关
- `GET /api/gifts` - 获取礼物列表
- `POST /api/gifts` - 创建新礼物
- `DELETE /api/gifts/[id]` - 删除礼物
- `POST /api/gifts/redeem` - 兑换礼物

#### 5.3.4 设置相关
- `GET /api/settings/redemption-day` - 获取兑换日设置
- `POST /api/settings/redemption-day` - 保存兑换日设置

### 5.4 时间处理规范

#### 5.4.1 时区处理
- **所有时间判断使用北京时间（UTC+8）**
- UTC时间转换为北京时间的计算：
  ```typescript
  const utcTimestamp = new Date().getTime()
  const beijingOffset = 8 * 60 * 60 * 1000
  const beijingTimestamp = utcTimestamp + beijingOffset
  const beijingDate = new Date(beijingTimestamp)
  ```

#### 5.4.2 "今天"的判断
- 使用北京时间的年、月、日来判断是否为同一天
- 任务完成记录的查询范围：
  - 开始：北京时间当天 00:00:00
  - 结束：北京时间当天 23:59:59

#### 5.4.3 倒计时计算
- 每秒更新一次
- 计算当前北京时间的总秒数
- 根据是否在兑换期计算不同的倒计时

## 6. 业务规则

### 6.1 任务完成规则
1. 同一个任务每天只能完成一次
2. 使用北京时间判断"今天"
3. 完成后立即获得积分
4. 家长可以撤销当天的完成记录
5. 撤销后扣除相应积分

### 6.2 礼物兑换规则
1. 只能在设定的兑换日兑换
2. 积分必须足够才能兑换
3. 兑换后立即扣除积分
4. 兑换记录不存储在数据库（仅扣除积分）

### 6.3 兑换日规则
1. 由家长设置
2. 支持多选（可以选择多个日期）
3. 设置后需要点击"保存"按钮
4. 使用北京时间判断当前是否为兑换日

### 6.4 积分规则
1. 当前积分：可用于兑换
2. 累计积分：历史总获得，不因兑换减少
3. 完成任务增加当前积分和累计积分
4. 兑换礼物只减少当前积分

### 6.5 撤销规则
1. 只能撤销当天的完成记录
2. 家长才有撤销权限
3. 撤销后扣除任务对应的积分
4. 完成记录标记为已撤销，但不删除

## 附录：术语表

| 术语 | 说明 |
|------|------|
| 兑换日 | 家长设置的每周允许孩子兑换礼物的日期，支持多选 |
| 倒计时 | 显示距离兑换日结束或下次兑换开始的时间 |
| 北京时间 | UTC+8 时区时间，用于判断日期和时间 |
| 当前积分 | 用户当前可用于兑换礼物的积分 |
| 累计积分 | 用户历史获得的总积分 |
| 任务完成记录 | 记录用户完成任务的详细信息，包括完成时间和是否被撤销 |
| 兑换期 | 当前时间处于兑换日当天的时间段 |
