# 技术栈说明

本文档详细说明项目使用的各项技术及其在项目中的具体用途。

## 1. 技术栈概述

### 1.1 项目定位

**家庭积分兑换系统** — 面向家庭的教育激励应用，双端设计（孩子端 + 家长端），移动优先。

### 1.2 技术栈核心原则

| 原则 | 说明 |
|------|------|
| 保持现状 | 基于现有 demo 版本，不做大幅升级 |
| 轻量优先 | 避免引入过多依赖，减少包体积 |
| 实用为主 | 选择适合项目规模的方案，避免过度设计 |
| 类型安全 | TypeScript 严格模式，Zod schema 验证 |
| 原型匹配 | UI 设计精确匹配原型规范 |

## 2. 核心框架

### 2.1 Next.js 14.2.0 (App Router)

| 方面 | 说明 |
|------|------|
| **用途** | 全栈框架，前端页面 + 后端 API 路由 |
| **路由模式** | App Router，`src/app/` 目录组织 |
| **渲染策略** | 客户端渲染（CSR），页面标记 `'use client'` |
| **API 路由** | `src/app/api/` 目录，服务端运行 |
| **部署** | EdgeOne Pages，腾讯云边缘平台 |

### 2.2 React 18.2.0

| 方面 | 说明 |
|------|------|
| **用途** | UI 构建库 |
| **状态管理** | TanStack React Query + React Context，详见后文 |

### 2.3 TypeScript 5.4.0

| 方面 | 说明 |
|------|------|
| **用途** | 类型安全的 JavaScript 超集 |
| **配置** | `strict: true`，`noImplicitAny: false` |
| **路径别名** | `@/*` 映射到 `./src/*`，简化模块导入 |

## 3. 样式方案

### 3.1 Tailwind CSS 3.4.4

| 方面 | 说明 |
|------|------|
| **用途** | 原子化 CSS 框架，通过类名组合实现样式 |
| **集成方式** | PostCSS 插件 |
| **配置** | `tailwind.config.ts` 定义主题变量（颜色、圆角、间距） |
| **工具函数** | `cn()` 函数（`clsx` + `tailwind-merge`）合并类名，避免冲突 |

### 3.2 shadcn/ui (New York 风格)

| 方面 | 说明 |
|------|------|
| **用途** | 可定制组件库，基于 Radix UI |
| **风格** | New York，紧凑间距、小圆角 |
| **组件位置** | `src/components/ui/` |
| **底层依赖** | `@radix-ui/react-*` 原语，确保无障碍访问 |
| **使用方式** | 复制代码模式，完全可控，可精确匹配原型设计 |

### 3.3 Lucide React

| 方面 | 说明 |
|------|------|
| **用途** | SVG 图标库 |
| **风格** | 简洁现代，与原型完全一致 |

### 3.4 得意黑字体（Smiley Sans Oblique）

## 4. 数据层

### 4.1 Prisma 7.8.0

| 方面 | 说明 |
|------|------|
| **用途** | TypeScript ORM，提供类型安全的数据库访问 |
| **Schema 位置** | `prisma/schema.prisma` |
| **ID 策略** | CUID 主键 |
| **客户端模式** | 开发环境全局单例，避免热重载多次连接 |
| **迁移方式** | 本地 `prisma migrate dev` 生成 SQL，Turso CLI 应用到远程 |

### 4.2 Turso (libSQL)

| 方面 | 说明 |
|------|------|
| **用途** | 边缘分布式数据库，基于 libSQL（SQLite 分支） |
| **连接方式** | HTTP 连接，通过 `@prisma/adapter-libsql` 适配 |
| **优势** | 全球分布式低延迟、自动备份、与 SQLite 100% 兼容 |
| **本地开发** | SQLite 文件（`dev.db`），无需 Turso 连接 |
| **生产连接** | `libsql://db-name-org.turso.io` + Auth Token 认证 |
| **自动切换** | 配置 `TURSO_DATABASE_URL` 时自动使用 Turso，否则本地 SQLite |

## 5. 状态管理

### 5.1 TanStack React Query

| 方面 | 说明 |
|------|------|
| **用途** | 服务端状态管理 |
| **管理内容** | 用户信息、任务列表、礼物列表、积分数据、完成记录 |
| **优势** | 自动缓存、后台同步、乐观更新、窗口聚焦刷新 |
| **乐观更新** | 点击"完成"立即显示成功效果，后台同步服务器 |
| **错误处理** | 请求失败自动回滚状态 |

### 5.2 React Context

| 方面 | 说明 |
|------|------|
| **用途** | 客户端状态管理 |
| **管理内容** | 登录状态、当前用户、UI 交互状态（弹窗、加载） |
| **理由** | 状态简单，不需要额外引入 Zustand |

### 5.3 状态划分

| 状态类型 | 管理方案 | 具体内容 |
|---------|---------|---------|
| 服务端状态 | React Query | API 获取的数据（任务、礼物、积分等） |
| 客户端状态 | React Context | 登录状态、弹窗状态、导航状态 |
| 组件状态 | useState | 局部 UI 状态（如折叠展开） |

## 6. 表单与验证

### 6.1 React Hook Form

| 方面 | 说明 |
|------|------|
| **用途** | 高性能表单状态管理 |
| **优势** | 非受控组件，输入时不触发组件重渲染 |
| **验证集成** | 通过 `@hookform/resolvers` 桥接 Zod schema 验证 |

### 6.2 Zod

| 方面 | 说明 |
|------|------|
| **用途** | TypeScript 优先的 schema 验证库 |
| **使用场景** | API 请求参数验证、表单输入验证 |
| **类型推断** | schema 自动生成 TypeScript 类型 |
| **shadcn/ui 集成** | Form 组件基于 react-hook-form + zod 构建 |

### 6.3 表单场景

| 表单 | 验证规则 |
|------|----------|
| 用户注册 | 用户名必填、密码≥6位、两次密码一致、角色必选 |
| 用户登录 | 用户选择、密码必填 |
| 创建任务 | 名称必填、积分必填且为数字 |
| 创建礼物 | 名称必填、积分必填且为数字 |
| 兑换日设置 | 至少选择一天 |

## 7. 日期处理

### 7.1 Day.js

| 方面 | 说明 |
|------|------|
| **用途** | 轻量级日期处理库 |
| **包体积** | 约 2KB |
| **插件** | timezone 插件处理时区 |
| **API** | 类似 Moment.js，简洁易用 |

### 7.2 北京时间处理

| 方面 | 说明 |
|------|------|
| **时区** | UTC+8，所有时间判断使用北京时间 |
| **任务判断** | "今天是否已完成"用北京时间判断 |
| **兑换日判断** | 北京时间的星期几，判断是否在兑换日列表 |
| **倒计时** | 距兑换结束/下次兑换的秒数，每秒更新 |

### 7.3 工具函数位置

`src/lib/date.ts` — 封装北京时间转换、格式化、判断函数。

## 8. 认证方案

### 8.1 自定义 Cookie 认证

| 方面 | 说明 |
|------|------|
| **用途** | 基于 Cookie 的会话管理 |
| **适用场景** | 家庭内部应用，用户数量有限 |
| **登录流程** | 登录 → 验证密码 → 设置 Cookie → 后续请求识别用户 |

### 8.2 bcryptjs

| 方面 | 说明 |
|------|------|
| **用途** | 密码哈希加密存储 |
| **算法** | bcrypt，行业标准，防彩虹表攻击 |
| **工作因子** | 默认 10 轮，平衡安全与性能 |

### 8.3 认证流程

| 操作 | 流程 |
|------|------|
| 注册 | 前端验证 → 密码哈希 → 存入数据库 → 设置登录 Cookie |
| 登录 | 选择用户 → 输入密码 → 验证 → 设置 Cookie |
| 登出 | 清除 Cookie → 返回登录页 |
| 认证检查 | API 中间件读取 Cookie → 验证用户身份 |

## 10. 动画方案

### 10.1 Tailwind CSS + 自定义 CSS

| 方面 | 说明 |
|------|------|
| **方案** | Tailwind `animate-*` 类 + 自定义 CSS `@keyframes` |
| **理由** | 动画简单，原型已定义完整代码，可直接迁移 |
| **无额外依赖** | 不需要 Framer Motion，保持轻量 |

### 10.2 动画类型

| 动画 | 实现 | 缓动函数 |
|------|------|----------|
| 弹窗弹出 | `scale(0.8) → scale(1)` | 弹性 `cubic-bezier(0.175, 0.885, 0.32, 1.275)` |
| 卡片悬停 | `translateY(-2px)` + shadow 变化 | `ease-out 150ms` |
| 星星旋转 | `rotate 20s linear infinite` | 线性 |
| Toast 弹出 | `scale(0) → scale(1.1) → scale(1)` | 弹性缓动 |
| 列表依次出现 | `animation-delay` 递增 50ms | `ease-out 300ms` |
| 积分数字弹出 | `scale(1.2) → scale(1)` | 弹性缓动 |

### 10.3 动画定义位置

`src/app/globals.css` — 定义所有自定义动画 keyframes 和 animate-* 类。

## 11. 项目结构

### 11.1 目录结构

```
src/
├── app/                    # Next.js App Router
│   ├── (auth)/             # 认证相关页面（登录、注册）
│   ├── (child)/            # 孩子端页面（任务、礼物、个人）
│   ├── (parent)/           # 家长端页面（统计、任务、礼物、设置）
│   ├── api/                # API 路由
│   │   ├── user/           # 用户相关接口
│   │   ├── tasks/          # 任务相关接口
│   │   ├── gifts/          # 礼物相关接口
│   │   └── settings/       # 设置相关接口
│   ├── globals.css         # 全局样式 + 动画定义
│   └── layout.tsx          # 根布局
│
├── components/
│   ├── ui/                 # shadcn/ui 基础组件
│   ├── child/              # 孩子端定制组件（积分卡片、任务卡片等）
│   ├── parent/             # 家长端定制组件
│   └── shared/             # 两端共享组件（底部导航、弹窗等）
│
├── lib/
│   ├── db.ts               # Prisma 客户端
│   ├── date.ts             # 北京时间处理
│   ├── auth.ts             # 认证相关
│   ├── cn.ts               # 类名合并工具
│   └── constants.ts        # 常量定义（颜色池等）
│
├── hooks/
│   ├── use-user.ts         # 用户状态 Context
│   └── use-task.ts         # 任务相关 Hooks
│
├── types/
│   └── index.ts            # 全局类型定义
│
└── providers/
│   ├── query-provider.tsx  # React Query Provider
│   └── user-provider.tsx   # 用户 Context Provider
```

### 11.2 路由分组说明

| 分组 | 说明 |
|------|------|
| `(auth)` | 登录、注册页面，共享布局 |
| `(child)` | 孩子端页面，共享底部导航 |
| `(parent)` | 家长端页面，共享底部导航 |

括号表示路由分组，不影响 URL 路径。
