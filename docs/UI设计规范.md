# 家庭积分兑换系统 - UI 设计规范

## 1. 设计理念

### 1.1 整体定位

本项目为家庭教育激励应用，采用双端设计：
- **孩子端**：童趣活泼、激励感强、操作简单
- **家长端**：简洁专业、清晰高效、管理便捷

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 统一基调 | 两端共享核心设计语言（字体、圆角、间距规范） |
| 差异化细节 | 通过配色、图标风格、卡片样式区分两端 |
| 激励优先 | 孩子端强调正向反馈，动画增强成就感 |
| 操作简化 | 减少步骤，核心操作一触即达 |
| 移动优先 | 针对手机屏幕优化，触摸友好 |

## 3. 字体系统

### 3.1 字体来源

采用**得意黑（Smiley Sans）**作为孩子端主字体，国内CDN托管，童趣倾斜风格：

```html
<link href="https://cdn.jsdelivr.net/npm/smiley-sans@1.1.1/dist/SmileySans-Oblique.min.css" rel="stylesheet">
```

> 说明：得意黑是字节跳动开源的中文倾斜字体，风格活泼童趣，非常适合儿童应用。通过 jsDelivr CDN 国内镜像加载，速度快且稳定。

### 3.2 字体定义

```css
font-family: 'Smiley Sans Oblique', 'PingFang SC', 'Microsoft YaHei', -apple-system, BlinkMacSystemFont, sans-serif;
```

| 优先级 | 字体 | 来源 |
|--------|------|------|
| 1 | Smiley Sans Oblique | jsDelivr CDN（国内镜像） |
| 2 | PingFang SC | macOS/iOS 系统内置 |
| 3 | Microsoft YaHei | Windows 系统内置 |
| 4 | 系统默认 | 各平台系统字体 |

## 7. 动画系统

### 7.1 动画时长

| 名称 | 时长 | 用途 |
|------|------|------|
| 快 | `150ms` | 悬停状态、按钮反馈 |
| 中 | `300ms` | 卡片展开、页面切换 |
| 慢 | `500ms` | 弹窗出现、积分弹出 |
| 庆祝 | `800ms` | 星星飘落、彩带效果 |

### 7.2 缓动函数

| 名称 | 值 | 用途 |
|------|-----|------|
| 标准 | `ease-out` | 元素出现 |
| 弹性 | `cubic-bezier(0.175, 0.885, 0.32, 1.275)` | 积分弹出、庆祝效果 |
| 平滑 | `ease-in-out` | 页面切换 |

### 7.3 交互动画

#### 完成任务动画

1. 点击完成按钮 → 按钮缩放 `0.95` → `1`（150ms）
2. 确认后 → 积分数字放大弹出 `scale(1.2)` → `scale(1)`（300ms，弹性缓动）
3. 同时 → 2-3颗小星星从按钮位置飘落（500ms）
4. 弹出提示 "获得 X 积分！" → 自动消失（800ms）

#### 兑换礼物动画

1. 点击礼物卡片 → 卡片轻微上浮 `translateY(-2px)`（150ms）
2. 确认弹窗出现 → 淡入 + 轻微放大（300ms）
3. 确认后 → 显示 "等待家长确认" 状态

#### 里程碑庆祝动画

当积分达到里程碑（如 100、500、1000）时：
1. 全屏半透明遮罩淡入
2. 多颗星星从中心向外飞舞（800ms）
3. 彩带从顶部飘落（600ms）
4. 中央显示庆祝弹窗（动画弹入）
5. 点击关闭 → 所有元素淡出

### 7.4 列表动画

任务列表、礼物列表加载时：
```css
animation: fadeSlideUp 300ms ease-out;
animation-delay: calc(var(--index) * 50ms); /* 依次出现 */
```

## 9. 图标规范

### 9.1 图标库选择

#### 主图标库

使用 **Lucide Icons** 作为主图标库：
- **风格特点**：简洁、现代、统一的设计语言
- **技术实现**：Vue 组件封装，支持动态颜色和尺寸
- **优势**：图标数量丰富（超过 1000 个），开源免费

```typescript
// 安装
pnpm add lucide-vue-next

// 使用示例
import { CheckCircle, Gift, Star } from 'lucide-vue-next'
```

#### 补充图标库

对于 Lucide 没有的特殊图标，使用 **Iconify** 作为补充：

```typescript
// 安装
pnpm add @iconify/vue

// 使用示例
import { Icon } from '@iconify/vue'

// 可以访问多个图标集
<Icon icon="mdi:emoticon-happy" />
<Icon icon="fluent-emoji:star" />
```

#### 特殊场景图标

| 场景 | 推荐来源 | 说明 |
|------|---------|------|
| 表情/情绪 | `fluent-emoji` 图标集 | 孩子端庆祝、情绪表达 |
| 星星/奖励 | Lucide `Star` + 自定义动画 | 积分展示、奖励提示 |
| 徽章/成就 | 自定义 SVG | 里程碑徽章、特殊成就 |

### 9.2 图标设计原则

#### 基本原则

| 原则 | 说明 |
|------|------|
| 风格统一 | 全项目使用 Lucide 的线性图标风格，保持一致性 |
| 意义明确 | 图标含义需一目了然，避免歧义 |
| 适度简化 | 移动端图标不宜过于复杂，细节适中 |
| 触摸友好 | 点击区域足够大，易于操作 |

#### 孩子端图标特点

- **更圆润**：优先选择带有圆形元素的图标（如 `CheckCircle` 而非 `Check`）
- **更活泼**：配合动画效果使用
- **更直观**：选择孩子容易理解的图标
- **鼓励感**：使用正向图标，避免警告/禁止类图标单独出现

#### 家长端图标特点

- **更简洁**：直接使用基础图标（如 `Check` 而非 `CheckCircle`）
- **更专业**：管理类图标使用标准样式
- **功能性**：图标以功能导向为主，减少装饰性

### 9.3 图标尺寸规范

#### 标准尺寸

| 2xl（超大） | `48px` | `1px` | 庆祝动画、里程碑展示 |

### 9.11 图标使用最佳实践

#### 避免的做法

| ❌ 避免 | 原因 |
|---------|------|
| 混用不同风格图标库 | 风格不一致，视觉混乱 |
| 过多装饰性图标 | 分散注意力，降低可用性 |
| 图标含义模糊 | 用户无法理解功能 |
| 图标过小（<14px） | 无法识别，触摸困难 |
| 颜色含义混乱 | 红色用于成功等错误用法 |
| 图标无触摸区域 | 点击困难，体验差 |

#### 推荐的做法

| ✓ 推荐 | 原因 |
|---------|------|
| 保持图标风格统一 | 视觉一致，专业感 |
| 图标配合文字说明 | 增强可理解性 |
| 重要操作提供视觉反馈 | 点击、成功动画 |
| 保持足够点击区域 | 触摸友好（≥44px） |
| 颜色遵循功能色规范 | 状态一目了然 |
| 加载/禁用状态明确 | 状态清晰可辨 |

## 15. 礼物颜色池定义

系统预设 6 种礼物背景色，创建礼物时随机分配：

```typescript
const GIFT_COLOR_POOL = [
  { name: '活力橙', value: '#FF6B35' },
  { name: '薄荷绿', value: '#4ECDC4' },
  { name: '奶黄', value: '#FFD93D' },
  { name: '天蓝', value: '#60A5FA' },
  { name: '紫罗兰', value: '#A78BFA' },
  { name: '蜜橙', value: '#FB923C' },
];

function getRandomGiftColor() {
  return GIFT_COLOR_POOL[Math.floor(Math.random() * GIFT_COLOR_POOL.length)].value;
}
```
