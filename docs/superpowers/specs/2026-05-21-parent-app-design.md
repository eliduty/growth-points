# 家长端应用设计

## 1. 使用场景定位

### 1.1 频率分析

| 功能 | 使用频率 | 分析理由 |
|------|---------|---------|
| 查看统计 | 中高频 | 家长想了解孩子本周完成情况，可能每周几次查看 |
| 撤销操作 | 低频 | 孩子误完成或需要调整时才使用，不是每天都有 |
| 任务管理 | 低频 | 任务通常是固定的日常任务，设置后很少改动 |
| 礼物管理 | 低频 | 礼物列表相对固定，偶尔补充或更新 |
| 兑换日设置 | 极低频 | 设置一次后基本稳定 |
| 成员管理 | 极低频 | 添加新成员是一次性操作 |

### 1.2 核心场景

家长端是「移动端 + 查看为主 + 周期性管理调整」：
- 家长打开应用，主要是查看孩子本周进度
- 偶尔需要撤销孩子的误操作
- 定期（如周末）可能调整任务或补充礼物

---

## 2. 页面结构

### 2.1 整体架构

家长端采用四页面结构，配合底部导航：

| 页面 | 定位 | 核心内容 |
|------|------|---------|
| 首页（统计页） | 高频查看 | 本周各孩子完成情况概览 + 撤销完成记录 |
| 任务页 | 低频管理 | 任务列表 + 创建/删除操作 + 类别管理 |
| 礼物页 | 低频管理 | 礼物列表 + 创建/删除操作 + 撤销兑换记录 |
| 设置页 | 极低频管理 | 成员管理、兑换日设置、个人信息、退出登录 |

**底部导航：**

```
[统计]  [任务]  [礼物]  [设置]
```

## 3. 统计页设计

### 3.1 页面布局

```
┌─────────────────────────────┐
│   本周统计（5月19日-25日）     │ ← 标题带日期范围
├─────────────────────────────┤
│  ┌─────────┐  ┌─────────┐    │ ← 孩子概览卡片（横向滑动）
│  │  小明   │  │  小红   │    │
│  │  完成5个│  │  完成3个│    │   显示：本周完成任务数
│  │  +45积分│  │  +25积分│    │   显示：本周获得积分
│  └─────────┘  └─────────┘    │
│    ← 滑动查看更多 →          │   孩子多时横向滑动
├─────────────────────────────┤
│                             │
│  【小明本周记录】▼ 已展开     │ ← 默认展开第一个孩子
│    阅读书籍   5月21日 +10    │
│               09:30  [撤销]  │ ← 撤销按钮在每条记录右侧
│    整理房间   5月20日 +5     │
│               15:20  [撤销]  │
│    本周共完成 5 个任务        │
│                             │
│  【小红本周记录】▶ 点击展开   │ ← 其他孩子默认折叠
│                             │
└─────────────────────────────┘
```

### 3.2 设计要点

| 要点 | 说明 |
|------|------|
| 概览卡片 | 紧凑展示核心数据（完成数+积分），一屏可见所有孩子对比 |
| 横向滑动 | 孩子超过2个时卡片横向滑动，不占用垂直空间 |
| 详情折叠 | 每个孩子的记录列表可独立折叠，减少一屏信息密度 |
| 默认展开第一个 | 进入页面时第一个孩子的记录默认展开，减少操作步骤 |
| 撤销按钮位置 | 放在每条记录右侧，看完发现问题立即操作 |

### 3.3 撤销完成记录交互

**操作流程：**

```
点击撤销 → 弹出确认框 → 确认后扣回积分 → 记录移除 → 弹出"已撤销"提示
```

**撤销范围：** 本周内的完成记录均可撤销

**确认框内容：**

```
┌─────────────────────────┐
│   确认撤销这条完成记录？   │
│                         │
│   任务：阅读书籍         │
│   将扣回：10 积分        │
│                         │
│   [取消]    [确认撤销]   │
└─────────────────────────┘
```

## 4. 任务页设计

### 4.1 页面布局

```
┌─────────────────────────────┐
│      [管理类别]    [+添加]   │ ← 顶部两个操作按钮
├─────────────────────────────┤
│                             │
│ 【学习类】▼ 已展开           │ ← 类别分组，可折叠
│   阅读书籍     +10积分 [删除]│
│   练习写字     +5积分  [删除]│
│                             │
│ 【家务类】▶ 点击展开         │ ← 其他类别默认折叠
│                             │
│ 【运动类】▶ 点击展开         │
│                             │
│                             │
│        (暂无任务)            │ ← 空状态提示
│                             │
└─────────────────────────────┘
```

### 4.2 设计要点

| 要点 | 说明 |
|------|------|
| 顶部按钮 | 左侧「管理类别」，右侧「添加任务」，操作入口明确 |
| 类别折叠 | 支持折叠/展开，默认第一个类别展开 |
| 删除按钮 | 每个任务右侧有删除按钮，点击后确认删除 |
| 空状态 | 类别下无任务时显示「暂无任务」提示 |

### 4.3 创建任务交互

**弹窗表单：**

```
┌─────────────────────────────┐
│         添加任务            │
├─────────────────────────────┤
│  任务名称                   │
│  [________________]         │
│                             │
│  积分值                     │
│  [____] 积分                │
│                             │
│  所属类别                   │
│  [学习类        ▼]          │ ← 下拉选择已有类别
│                             │
│  任务描述（可选）            │
│  [________________]         │
│  [________________]         │
│                             │
│   [取消]      [确认添加]    │
└─────────────────────────────┘
```

**字段说明：**

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 任务名称 | 必填 | 任务标题 |
| 积分值 | 必填 | 完成任务获得的积分，数字 |
| 所属类别 | 必填 | 下拉选择已有类别 |
| 任务描述 | 可选 | 任务的规则说明，孩子端点击任务可查看 |

### 4.4 类别管理

**管理类别弹窗：**

点击「管理类别」后弹出类别列表，可添加新类别、删除已有类别。

**删除类别规则：**

| 规则 | 说明 |
|------|------|
| 禁止删除有任务的类别 | 类别下有任务时不允许删除，需先清空任务 |
| 提示信息 | 「该类别下有 X 个任务，请先删除任务」 |

## 5. 礼物页设计

### 5.1 页面布局

```
┌─────────────────────────────┐
│            [+添加]          │ ← 顶部添加按钮
├─────────────────────────────┤
│  ┌─────────┐  ┌─────────┐    │ ← 两列网格，与孩子端一致
│  │ ■■■■■■ │  │ ■■■■■■ │    │
│  │  玩具车 │  │   绘本  │    │
│  │  50积分 │  │  30积分 │    │
│  │ [删除]  │  │ [删除]  │    │ ← 每个卡片底部有删除按钮
│  └─────────┘  └─────────┘    │
│                             │
│  ┌─────────┐  ┌─────────┐    │
│  │ ■■■■■■ │  │ ■■■■■■ │    │
│  │  冰淇淋 │  │  电影票 │    │
│  │  20积分 │  │ 100积分 │    │
│  │ [删除]  │  │ [删除]  │    │
│  └─────────┘  └─────────┘    │
├─────────────────────────────┤
│                             │
│ 【待确认兑换】（2 条）        │ ← 待确认兑换区域
│   小明兑换了「绘本」 5月21日 │
│   -30积分    [确认] [撤销]   │ ← 确认和撤销按钮
│                             │
│   小红兑换了「冰淇淋」5月21日│
│   -20积分    [确认] [撤销]   │
│                             │
├─────────────────────────────┤
│                             │
│ 【已确认兑换】（本周）        │ ← 已确认兑换区域
│   小明兑换了「玩具车」5月20日│
│   -50积分                   │ ← 已确认无撤销按钮
│                             │
└─────────────────────────────┘
```

### 5.2 设计要点

| 要点 | 说明 |
|------|------|
| 礼物卡片布局 | 与孩子端一致的两列网格，保持视觉统一 |
| 删除按钮 | 每个卡片底部有删除按钮，点击后确认删除 |
| 待确认兑换区域 | 孩子兑换后等待家长确认，可确认或撤销 |
| 已确认兑换区域 | 家长确认后的记录，不可撤销，锁定状态 |
| 兑换记录范围 | 待确认显示全部，已确认显示本周 |

### 5.3 兑换确认交互

**确认兑换流程：**

```
点击确认 → 弹出确认框 → 确认后状态变为"已确认" → 记录移至已确认区域 → 孩子端显示"兑换成功"
```

**确认框内容：**

```
┌─────────────────────────┐
│   确认兑换这个礼物？      │
│                         │
│   孩子：小明             │
│   礼物：绘本             │
│   积分：30               │
│                         │
│   确认后不可撤销         │
│                         │
│   [取消]    [确认兑换]   │
└─────────────────────────┘
```

**撤销兑换流程：**

```
点击撤销 → 弹出确认框 → 确认后返还积分 → 记录移除 → 孩子端显示"兑换已取消"
```

**撤销确认框内容：**

```
┌─────────────────────────┐
│   确认撤销这条兑换记录？   │
│                         │
│   礼物：绘本             │
│   将返还：30 积分        │
│                         │
│   [取消]    [确认撤销]   │
└─────────────────────────┘
```

**设计考量：**
- 家长参与兑换确认，更有仪式感
- 待确认状态下可撤销，积分返还，无损失
- 确认后锁定不可撤销，避免事后争议

### 7.1 家长端登录页

│                             │
├─────────────────────────────┤
│                             │
│        用户登录              │ ← 当前模式标题
│                             │
│  用户名                      │
│  [________________]          │
│                             │
│  密码                        │
│  [________________]          │

## 8. 撤销操作汇总

| 撤销类型 | 入口页面 | 积分变化方向 | 记录范围 | 状态要求 |
|---------|---------|-------------|---------|---------|
| 撤销完成记录 | 统计页 | 扣回积分 | 本周完成记录 | 无限制 |
| 撤销兑换记录 | 礼物页 | 返还积分 | 待确认状态 | 仅待确认可撤销 |

**已确认的兑换记录不可撤销。**

## 9. 移动端适配要点

| 适配点 | 处理方式 |
|------|---------|
| 统计页概览 | 孩子卡片横向滑动，减少垂直空间占用 |
| 统计页详情 | 可折叠，本周默认展开第一个孩子 |
| 任务列表 | 类别分组可折叠，减少一屏信息密度 |
| 礼物列表 | 两列网格，与孩子端保持一致 |
| 弹窗表单 | 一屏可完成填写，无需页面跳转 |
| 底部导航 | 4个入口，手指易触达 |
| 操作按钮 | 明确点击区域，适合触摸操作 |
