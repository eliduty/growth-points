# 家庭积分兑换系统 - 术语表

## 一、用户与角色

| 术语 | 英文标识 | 说明 |
|------|---------|------|
| **家长** | `PARENT` | 管理端角色，负责任务/礼物管理、成员管理、兑换确认等 |
| **孩子** | `CHILD` | 使用端角色，完成任务、积累积分、兑换礼物 |
| **家庭** | `Family` | 系统核心组织单位，用户必须属于一个家庭才能使用系统 |
| **成员** | `Member` | 家庭内的所有用户，包括家长和孩子 |
| **创始家长** | — | 注册时创建家庭的第一个家长 |

## 二、核心业务实体

| 术语 | 英文标识 | 说明 |
|------|---------|------|
| **任务** | `Task` | 家务任务，有积分值，属于某个类别 |
| **类别** | `Category` | 任务分类（如"日常家务"、"学习任务"），家庭内维护，可排序 |
| **礼物** | `Gift` | 可兑换的奖励物品，有积分价格、每周兑换上限、颜色等属性 |
| **任务完成记录** | `TaskCompletion` | 孩子完成任务的记录，包含积分快照 |
| **礼物兑换记录** | `GiftRedemption` | 孩子兑换礼物的记录，包含兑换状态 |
| **兑换日** | `ExchangeDay` | 每周允许兑换礼物的日期设置（如周一、周三） |
| **奖励** | `Reward` | 家长给孩子发放的一次性积分奖励，需填写原因（必填，≤50字符） |

## 三、积分系统

| 术语 | 英文标识 | 说明 |
|------|---------|------|
| **当前积分** | `currentPoints` | 孩子当前可用的积分余额 |
| **累计积分** | `totalPoints` | 孩子从系统获得的积分总和（历史累计） |
| **积分快照** | `points` (在记录中) | 完成记录/兑换记录中存储的当时积分值，不受后续任务/礼物积分修改影响 |

## 四、兑换状态

| 术语 | 英文标识 | 说明 |
|------|---------|------|
| **待确认** | `PENDING` | 孩子已兑换，等待家长确认 |
| **已确认** | `CONFIRMED` | 家长已确认兑换，锁定状态，不可撤销 |
| **已撤销** | `CANCELLED` | 家长已撤销兑换请求，积分已返还 |

## 五、任务可用日期

| 术语 | 英文标识 | 说明 |
|------|---------|------|
| **可用日期** | `availableDays` | 任务的可用日期，存储为逗号分隔字符串（如 `"1,3,5"` 表示周一三五） |
| **待安排** | `pending` (status) | 任务未设置可用日期（`availableDays` 为 null），孩子端不显示 |
| **已安排** | `arranged` (status) | 任务已设置可用日期，孩子端按日期规则显示 |
| **今日待办** | — | 今天可用且未完成的任务分组 |
| **已完成** | — | 今天完成的任务分组 |
| **其他时间** | — | 今天不可用的任务分组，灰色显示，标注可用日期 |
| **日期编码** | `dayOfWeek` | 0=周日, 1=周一, ..., 6=周六 |

## 六、时间相关

| 术语 | 英文标识 | 说明 |
|------|---------|------|
| **时区偏移量** | `timezoneOffset` | 用户时区偏移（如 +8 = 8, -5 = -5），用于日期判断 |
| **周起始时间** | `weekStart` | 本周周一 00:00:00（按用户时区计算） |
| **本周** | — | 从周一 00:00:00 到周日 23:59:59（一周从周一开始） |
| **今天** | — | 使用用户本地时区判断 |

## 七、撤销操作

| 术语 | 英文标识 | 说明 |
|------|---------|------|
| **撤销完成** | `revokedAt/revokedBy` | 撤销任务完成记录，扣回积分（仅本周内可操作） |
| **撤销兑换** | `cancelledAt/cancelledBy` | 撤销礼物兑换请求（仅待确认状态可操作） |
| **积分不足自动关联撤销** | — | 撤销完成记录时若孩子积分不足，系统自动按时间顺序撤销待确认的兑换记录以返还积分 |

## 八、应用架构

| 术语 | 英文标识 | 说明 |
|------|---------|------|
| **家长端** | `/parent/*` | 家长使用的管理界面路由，蓝色渐变主题 |
| **孩子端** | `/child/*` | 孩子使用的任务/礼物界面路由，橙色渐变主题 |
| **软删除** | `deletedAt` | 任务/礼物删除时设置时间戳而非物理删除 |
| **单体应用双入口** | — | 单一 Next.js 应用，`/parent/*` 和 `/child/*` 两套独立页面路由 |

## 九、会话与认证

| 术语 | 英文标识 | 说明 |
|------|---------|------|
| **JWT Token** | — | 使用 jose 库创建的会话令牌，HS256 算法签名 |
| **JWT_SECRET** | — | JWT 签名密钥 |
| **Session Cookie** | `family_points_session` | 存储 JWT Token 的 Cookie 名称 |
| **Token 有效期** | 7 days | JWT Token 过期时间 |
| **Session 数据** | `SessionData` | 包含 userId, role, familyId |
| **Web Crypto API** | — | 用于加密操作，兼容 Edge runtime |
| **Edge runtime** | — | EdgeOne 边缘运行环境 |

## 十、礼物相关

| 术语 | 英文标识 | 说明 |
|------|---------|------|
| **每周兑换上限** | `weeklyLimit` | 礼物每周可兑换次数限制，null 表示无限制，最小值为 1 |
| **本周已兑换** | `weeklyRedeemed` | 本周已兑换次数（统计 PENDING + CONFIRMED） |
| **上限状态** | `limitStatus` | `unlimited`（无限制）、`available`（可兑换）、`exhausted`（已用尽） |
| **礼物颜色** | `color` | 从预设颜色池随机分配的颜色值 |
| **礼物描述** | `description` | 礼物的说明文字（可选） |

## 十一、API 错误码

| 术语 | 说明 |
|------|------|
| **错误码 1001** | 用户名已存在 |
| **错误码 1002** | 用户名格式错误 |
| **错误码 1003** | 密码格式错误 |
| **错误码 1004** | 用户名或密码错误 |
| **错误码 2001** | 积分不足 |
| **错误码 2002** | 今日已完成该任务 |
| **错误码 2003** | 非兑换日 |
| **错误码 2004** | 本周兑换已达上限 |
| **错误码 2005** | 只能撤销本周记录 |
| **错误码 2006** | 只能撤销待确认状态 |
| **错误码 3001** | 类别下存在任务 |
| **错误码 3002** | 礼物名称已存在 |
| **错误码 3003** | 最后一个家长不可删除 |
| **错误码 4001** | 未登录 |
| **错误码 4002** | 无权限 |
| **错误码 4003** | 资源不存在 |
| **错误码 5001** | 网络异常 |

## 十二、UI 组件

| 术语 | 英文标识 | 说明 |
|------|---------|------|
| **TopNavbar** | — | 顶部导航栏组件，固定在页面顶部，高度 56px |
| **Toast 通知** | — | 底部居中的提示消息，2.5秒自动消失 |
| **Toast 状态类型** | `success/error/warning/info` | 四种通知状态，使用固定功能色（不随主题变化） |
| **确认弹窗** | `ConfirmDialog` | 自定义确认对话框组件 |
| **Loading 加载状态** | — | 按钮内 spinner / 列表骨架屏 / 全局遮罩 spinner |
| **底部导航** | — | 移动端底部导航栏 |

## 十三、UI 样式与主题

| 术语 | 英文标识 | 说明 |
|------|---------|------|
| **主题切换** | `data-role` 属性 | 通过 `data-role='parent'` 或 `data-role='child'` 切换 CSS 变量主题 |
| **主色** | `primary` | CSS 变量主色 |
| **次色** | `secondary` | CSS 变量次色 |
| **功能色** | `success/warning/error/info` | 固定功能色（Toast 使用） |
| **Toast success 色** | `#4ECDC4` | 青绿色 |
| **Toast error 色** | `#FF6B6B` | 珊瑚红 |
| **Toast warning 色** | `#FFD93D` | 金黄 |
| **Toast info 色** | `#60A5FA` | 天蓝 |
| **家长端主题色** | `#5B7FFF → #7B9FFF` | 蓝色渐变 |
| **孩子端主题色** | `#FF6B35 → #FF8A50` | 橙色渐变 |
| **孩子头像背景** | `#FFF0E8 → #FFE8DC` | 橙色渐变 |
| **家长头像背景** | `#E8F0FE → #F0F4FF` | 蓝色渐变 |

## 十四、交互规范

| 术语 | 说明 |
|------|------|
| **长按操作** | 500ms 触发，卡片背景变为 `#F0F4FF`，缩放 `scale(0.98)` |
| **「···」更多操作** | 24px × 24px 图标，点击区域最小 44px × 44px |
| **底部菜单** | 白色背景，顶部圆角 16px，选项高度 48px |
| **点击区域** | 最小 44px × 44px（移动端触摸友好） |
| **blur + 提交双验证** | 输入框 blur 时验证，提交时统一验证所有字段 |

## 十五、动画

| 术语 | 说明 |
|------|------|
| **Framer Motion** | 动画库 |
| **页面切换动画** | 滑动切换，向前左滑进入，向后右滑进入 |
| **积分变化动画** | 简单放大弹回效果 `scale(1 → 1.2 → 1)` |

## 十六、PWA

| 术语 | 英文标识 | 说明 |
|------|---------|------|
| **Manifest** | — | PWA 配置文件 |
| **Standalone 模式** | — | 应用以独立模式启动（无浏览器 UI） |
| **apple-touch-icon** | 180x180 | iOS 设备图标 |
| **favicon.ico** | — | 浏览器标签图标 |
| **Android 图标** | 192x192 / 512x512 | Android 设备图标 |

## 十七、输入规则

| 术语 | 规则 |
|------|------|
| **用户名** | 2-20 字符，仅允许中文、英文、数字 |
| **密码** | 6-32 位，无复杂度要求 |
| **类别名称** | 家庭内唯一，不限制长度 |
| **奖励原因** | 必填，≤50 字符 |
| **积分范围** | 任务/礼物积分不限制 |

## 十八、页面结构

| 角色 | 页面结构 |
|------|---------|
| **家长端底部导航** | [统计] [任务] [礼物] [设置] |
| **孩子端底部导航** | [任务] [礼物] [我的] |

## 十九、组件目录规范

| 术语 | 说明 |
|------|------|
| **PascalCase** | 组件命名采用 PascalCase，如 `TaskCard.tsx` |
| **组件文件夹结构** | 以组件为单位文件夹，`index.tsx` 对外暴露，内部子组件不暴露 |
| **Hooks 扁平结构** | `hooks/` 目录下扁平存放 `useXxx.ts` |

## 二十、技术栈

| 术语 | 说明 |
|------|------|
| **Next.js** | 前端框架，单体应用双入口架构 |
| **Prisma** | ORM，配合 SQLite 数据库 |
| **Tailwind CSS** | CSS 框架，配合 CSS 变量实现主题切换 |
| **Framer Motion** | 动画库 |
| **jose** | JWT 库，用于会话管理 |
| **bcrypt** | 密码加密，cost factor = 12 |
| **CUID** | ID 格式（Prisma 默认） |
