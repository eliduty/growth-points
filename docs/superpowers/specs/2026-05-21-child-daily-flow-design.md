# 孩子端日常使用流程设计

## 1. 页面结构

### 1.1 整体架构

孩子端采用三页面结构，配合底部导航：

| 页面 | 功能 | 使用频率 |
|------|------|---------|
| 任务页（首页） | 积分概览 + 任务列表 | 高频 |
| 礼物页 | 礼物列表 + 兑换倒计时 + 兑换操作 | 中频 |
| 个人中心页 | 用户名 + 历史记录 + 退出登录 | 低频 |

**底部导航：**

```
[任务]  [礼物]  [我的]
```

## 2. 任务页设计

### 2.1 页面布局

```
┌─────────────────────────────┐
│        当前积分              │
│          120                │ ← 大字号突出显示
│   累计 350   本周 45         │ ← 小字号辅助信息
├─────────────────────────────┤
│ 【待完成】（5 个）            │
│                             │
│ 【学习类】▼ 已展开            │ ← 类别分组，可折叠
│   阅读书籍     +10积分 [完成] │
│   练习写字     +5积分  [完成] │
│                             │
│ 【家务类】▶ 点击展开          │ ← 其他类别默认折叠
│                             │
│ 【已完成】（2 个）            │ ← 已完成任务独立区域
│   整理房间     +5积分  ✓已完成│
└─────────────────────────────┘
```

### 2.2 积分概览

**展示内容：**
- 当前积分：大字号居中突出显示
- 累计获得：小字号辅助展示
- 本周获得：小字号辅助展示（"本周"定义为自然周：周一至周日）

**设计理由：**
- 当前积分是孩子最关心的核心数据
- 有层次感，不占用太多空间
- 激励感强，孩子一眼看到自己的成就

### 2.3 任务列表

**任务类别：**
- 类别由家长自定义创建（如学习类、家务类、运动类等）
- 类别可折叠，默认只展开第一个或全部折叠

**展示方式：**
- 按类别分组
- 每个任务一行式展示：任务名 + 积分 + 完成按钮
- 分"待完成"和"已完成"两个区域

**任务描述：**
- 家长创建任务时可填写规则描述（可选）
- 孩子端点击任务可查看描述详情

**已完成区域：**
- 当天完成的任务移至"已完成"区域
- 显示任务名 + 积分 + "已完成"标记
- 家长撤销后任务回到"待完成"区域

### 2.4 完成任务交互

**操作流程：**

```
点击"完成"按钮 → 弹出"确认完成？"气泡 → 点击确认 → 立即标记完成 → 积分立即增加 → 弹出"获得 X 积分！"提示 → 提示自动消失
```

**设计要点：**

| 要点 | 说明 |
|------|------|
| 简单确认 | 点击后弹出小气泡"确认完成？"，防止误触 |
| 即时激励 | 确认后立即获得积分，有成就感 |
| 流程简单 | 仅增加一步轻量确认，不影响体验流畅度 |
| 简单反馈 | 弹出提示让孩子感知到"完成了" |
| 家长可控 | 家长可撤销本周内的完成记录 |

**完成限制：**
- 同一个任务每天最多完成一次
- 次日可再次完成同一任务

**家长撤销机制：**
- 家长可撤销孩子当天的完成记录
- 撤销时检查当前积分是否足够扣回
- 积分不足时提示需先撤销相关兑换记录

## 3. 礼物页设计

### 3.1 页面布局

```
┌─────────────────────────────┐
│ 本周兑换日：周三、周六        │ ← 兑换日列表
│ 下次兑换还剩：2 天            │ ← 倒计时提示（非兑换日）
├─────────────────────────────┤
│ ■■■■■■   │ ■■■■■■           │ ← 彩色背景块
│  玩具车   │    绘本          │
│  50积分   │   30积分         │
├───────────┼─────────────────┤
│ ■■■■■■   │ ■■■■■■           │
│  冰淇淋   │   电影票         │
│  20积分   │   100积分        │
└───────────┴─────────────────┘
```

### 3.2 兑换日提示

**展示规则：**

| 状态 | 展示内容 |
|------|---------|
| 非兑换日 | 本周兑换日列表 + 下次兑换倒计时 |
| 兑换日当天 | "今日可兑换礼物！" |

**倒计时设计理由：**
- 信息完整：孩子知道一周有哪些兑换日
- 建立规律：孩子逐渐记住兑换日，形成习惯
- 倒计时直观：离下一个兑换日还有多久，一目了然

### 3.3 礼物列表

**展示方式：**
- 两列网格布局，紧凑卡片式
- 每个礼物卡片：彩色背景块 + 名称 + 积分值
- 彩色背景块由系统从预设颜色池中随机分配

**颜色池设计：**
- 系统预设一组颜色（8-12种）
- 家长创建礼物时自动随机分配
- 无需上传图片，简化操作

**设计理由：**
- 两列网格适合手机屏幕宽度
- 一屏可看到多个礼物，滚动浏览效率高
- 彩色背景有视觉吸引力，帮助孩子区分不同礼物

### 3.4 兑换日状态

**非兑换日：**
- 礼物卡片灰显
- 点击提示"兑换日才能兑换"

**兑换日：**
- 礼物卡片正常显示
- 点击可进行兑换操作

### 3.5 兑换礼物交互

**操作流程：**

```
点击礼物 → 弹出确认框 → 显示礼物详情 + 消耗积分 + 当前积分 → 点击确认 → 扣减积分 + 记录进入"待确认"状态 → 显示"等待家长确认"
```

**确认框内容：**
- 礼物名称
- 需扣积分
- 当前积分
- 确认兑换 / 取消按钮

**兑换后状态：**
- 孩子端显示"等待家长确认"
- 家长确认后，孩子端显示"兑换成功"
- 家长撤销后，积分返还，孩子端显示"兑换已取消"

**设计理由：**
- 兑换是"付出"行为，比完成任务更慎重
- 确认框帮助孩子理解"积分换礼物"的交换概念
- 防止误触，减少家长撤销压力
- 家长参与确认，更有仪式感和把控

## 4. 个人中心页设计

### 4.1 页面布局

```
┌─────────────────────────────┐
│                             │
│       欢迎，小明！            │ ← 用户名居中展示
│                             │
├─────────────────────────────┤
│  [任务历史]    [礼物历史]     │ ← Tab切换
│                             │
│  本周（5月19日-5月25日）▼     │ ← 本周默认展开
│    阅读书籍    5月21日 +10    │
│    整理房间    5月20日 +5     │
│    本周共完成 2 个，获 15积分  │
│                             │
│  上周（5月12日-5月18日）▶     │ ← 其他周折叠
│  两周前（5月5日-5月11日）▶    │
│  三周前（4月28日-5月4日）▶    │
│                             │
├─────────────────────────────┤
│        [退出登录]            │ ← 底部按钮
└─────────────────────────────┘
```

### 4.2 个人信息区

**展示内容：**
- 用户名（居中展示）

**设计理由：**
- 孩子只需要知道自己是谁，用户名足够
- 角色（孩子）对孩子无意义，孩子知道自己就是孩子
- 家庭名称对孩子是抽象概念，孩子端无家庭管理功能
- 符合孩子端"使用端"定位，信息精简

### 4.3 历史记录区

**Tab切换：**
- 任务历史
- 礼物历史

**展示方式：**
- 按周组织（最近4周）
- 本周默认展开，其他周折叠
- 点击折叠的周可展开查看详情
- 每周显示统计汇总（完成任务数/获得积分 或 兑换礼物数/消耗积分）

**任务历史：**
```
本周（5月19日-5月25日）
  ├─ 完成的任务列表（任务名 + 完成时间 + 获得积分）
  └─ 本周共完成 X 个任务，获得 X 积分
```

**礼物历史：**
```
本周（5月19日-5月25日）
  ├─ 兑换的礼物列表（礼物名 + 兑换时间 + 消耗积分）
  └─ 本周共兑换 X 个礼物，消耗 X 积分
```

### 4.4 退出登录

**位置：** 页面底部按钮

## 5. 首次登录体验

当孩子首次登录（家庭尚未添加任务）时：

**空状态提示：**
- 任务列表为空
- 显示提示文案："等待家长添加任务"
- 积分概览显示 0

**设计理由：**
- 明确告知孩子当前状态
- 避免孩子困惑为何看不到任务
- 引导孩子理解需要家长操作

## 6. 兑换日设置

### 6.1 设置方式

家长设置兑换规则，系统每周自动执行：

| 设置项 | 说明 |
|------|------|
| 兑换日 | 每周哪些天可兑换（如周三、周六），可选择 0-7 天 |
| 时间段 | 全天兑换（当天 00:00-23:59） |

**特点：**
- 设置一次，每周自动生效
- 支持多个兑换日（连续或不连续）
- 家长无需每周重复设置
- **允许不选择任何兑换日**：家长可以选择 0 天，暂时禁止兑换

### 6.2 孩子端展示

**未设置兑换日（选择了 0 天）：**
```
暂未设置兑换日，请联系家长
```

**非兑换日（已设置兑换日但当天不是）：**
```
本周兑换日：周三、周六
下次兑换还剩：X 天
```

**兑换日当天：**
```
今日可兑换礼物！
```

## 7. 移动端适配要点

| 适配点 | 处理方式 |
|------|---------|
| 积分概览 | 紧凑突出，当前积分大字号居中 |
| 类别分组 | 可折叠，减少一屏信息密度 |
| 任务列表 | 行式布局，一屏可看多个任务 |
| 礼物列表 | 两列网格，适合滚动浏览 |
| 历史记录 | 按周折叠，本周默认展开，减少滚动压力 |
| 底部导航 | 3个入口，手指易触达 |
| 完成按钮 | 明确点击区域，适合触摸操作 |
| 兑换确认 | 弹出框居中，适合移动端交互 |
