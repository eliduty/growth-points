# 任务页类别管理交互优化

## 背景

当前任务页类别管理采用"长按类别标题"触发，交互隐蔽，不符合高保真原型设计。

## 设计来源

参照高保真原型：`docs/prototypes/parent-tasks.html`

## 改动内容

### 1. 顶部操作栏

新增左右并列按钮：
- 左侧：「管理类别」按钮（次要按钮，齿轮图标）
- 右侧：「添加任务」按钮（主要按钮，加号图标）

点击「管理类别」弹出类别管理弹窗。

### 2. 类别分组卡片

重构为可折叠卡片结构：
- 白色背景卡片容器
- 类别标题区域：左侧图标+名称，右侧展开/折叠箭头
- 点击标题切换展开/折叠
- 展开时显示任务列表，折叠时隐藏

### 3. 任务卡片操作

每个任务直接显示操作按钮：
- 「编辑」按钮（铅笔图标）
- 「删除」按钮（垃圾桶图标）

移除长按触发方式。

### 4. 类别管理弹窗

改为居中弹窗形式：
- 显示已有类别列表（图标 + 名称 + 任务数量）
- 底部添加新类别输入框
- 「关闭」和「添加类别」按钮

移除长按类别标题触发底部菜单的方式。

## 文件改动

| 文件 | 改动 |

## 移除的功能

- 移除长按类别标题触发底部菜单
- 移除长按任务卡片触发底部菜单
- 移除页面底部的操作提示文字
