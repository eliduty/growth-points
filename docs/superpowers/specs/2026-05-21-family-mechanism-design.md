# 家庭积分兑换系统 - 家庭机制设计

## 1. 多孩子支持

### 1.1 积分模式：完全独立

每个孩子拥有独立的积分账户：
- 当前积分独立计算
- 累计积分独立计算
- 任务完成记录各自独立
- 礼物兑换各自独立，互不影响

### 1.2 任务列表：全家共用

- 家庭维护一个统一的任务池
- 所有孩子看到同样的任务列表
- 同一个任务可以被多个孩子各自完成
- 每个孩子完成任务后各自获得对应积分

### 1.3 礼物列表：全家共用

- 家庭维护一个统一的礼物池
- 所有孩子看到同样的礼物列表
- 孩子使用自己的积分兑换礼物
- 礼物兑换记录独立（不共用库存概念）

---

## 2. 家庭绑定机制

### 2.1 家庭概念

- 每个用户必须属于一个家庭才能使用系统
- 家庭是系统的核心组织单位
- 任务、礼物、设置均在家庭层面管理

### 2.2 单家庭限制

- 一个用户只能属于一个家庭
- 不支持同时加入多个家庭的场景

---

## 3. 用户注册与账号创建

### 3.1 家长账号

**注册方式：自主注册**

流程：
1. 家长填写注册信息（用户名、密码）
2. 选择角色为"家长"
3. 系统自动创建一个新家庭
4. 家长成为该家庭的第一个成员（创始家长）
5. 跳转到家庭管理界面

### 3.2 孩子账号

**创建方式：家长直接创建**

流程：
1. 家长在家庭管理页面点击"添加孩子"
2. 填写孩子信息（用户名、密码）
3. 系统创建孩子账号，自动绑定到当前家庭
4. 孩子账号立即可用

特点：
- 孩子不需要自主注册
- 孩子账号由家长创建和管理
- 孩子只需登录即可使用系统

---

## 4. 家长角色

### 4.1 多家长支持

- 家庭可以有多个家长
- 适用于父母双方共同管理孩子任务的场景

### 4.2 权限设计

**所有家长权限相同**

每个家长都可以执行以下操作：

| 功能模块 | 权限 |
|---------|------|
| 任务管理 | 创建、删除任务 |
| 礼物管理 | 创建、删除礼物 |
| 兑换日设置 | 设置每周兑换日 |
| 积分查看 | 查看所有孩子的积分信息 |
| 完成统计 | 查看本周所有孩子的完成情况 |
| 撤销操作 | 撤销任意孩子当天的完成记录 |
| 成员管理 | 添加孩子、添加家长、删除成员 |

---

## 5. 家庭成员管理规则

### 5.1 添加成员

**添加孩子**
- 所有家长都可以添加孩子账号
- 添加的孩子自动绑定到当前家庭

**添加家长**
- 所有家长都可以添加其他家长账号
- 新添加的家长与现有家长权限相同

### 5.2 删除家长

**组合规则**

| 规则 | 说明 |
|------|------|
| 不能删除自己 | 家长不能删除自己的账号 |
| 最后一个家长保护 | 家庭必须保留至少一个家长，不能删除最后一个家长账号 |

### 5.3 删除孩子

- 所有家长都可以删除孩子账号
- 删除后孩子账号及其数据一并清除
- 删除前的完成记录和兑换记录是否保留待后续讨论

### 5.4 孩子离开家庭

**不允许自主离开**
- 孩子不能主动申请离开家庭
- 孩子账号只能由家长删除

---

## 6. 数据隔离

### 6.1 家庭间隔离

- 不同家庭的数据完全隔离
- 任务、礼物、设置仅在家庭内部可见
- 不同家庭可以有不同的任务和礼物设置

### 6.2 家庭内数据共享

- 任务列表：家庭内所有成员可见
- 礼物列表：家庭内所有成员可见
- 兑换日设置：家庭内统一生效
- 积分数据：家长可查看所有孩子，孩子只能查看自己
- 完成记录：家长可查看所有孩子，孩子只能查看自己

---

## 7. 应用形态

### 7.1 双端分离

系统分为两个独立应用：

| 端 | 定位 | 核心功能 |
|---|------|---------|
| 家长端 | 管理端 | 任务/礼物管理、成员管理、兑换日设置、统计查看 |
| 孩子端 | 使用端 | 查看任务、完成任务、积累积分、兑换礼物 |

**设计考量：**
- 界面简洁，各自只看相关功能
- 未来可独立扩展各端功能
- 需维护两个独立应用

---

## 8. 用户旅程流程

### 8.1 家长注册流程

**流程步骤：**

```
家长端注册页面 → 填写用户名、密码 → 系统自动创建家庭 → 注册成功 → 直接进入家庭管理界面
```

**设计要点：**

| 要点 | 决策 |
|------|------|
| 角色选择 | 无需选择，注册即家长 |
| 家庭名称 | 无需填写，系统自动生成内部ID |
| 首次进入 | 直接展示空状态管理界面，无特殊引导 |

**注册后状态：**
- 新家庭创建完成
- 家长成为创始家长
- 家庭内无孩子、无任务、无礼物
- 家长可自由操作管理功能
