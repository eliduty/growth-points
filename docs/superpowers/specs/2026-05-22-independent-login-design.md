# 独立登录入口设计

## 1. 概述

按照高保真原型设计，孩子端和家长端应有独立的登录入口。本设计将当前的统一登录页拆分为：
- 首页入口选择
- 家长端独立登录页
- 孩子端独立登录页

---

## 2. 路由结构

| 路径 | 页面 | 功能 |
|------|------|------|
| `/` | 首页 | 入口选择（"我是家长"、"我是孩子"） |
| `/parent/login` | 家长端登录 | 登录 + 注册 |
| `/child/login` | 孩子端登录 | 仅登录 |

---

## 3. 首页设计

**布局：**
```
┌─────────────────────────────┐
│                             │
│      家庭积分兑换系统        │
│                             │
│   ┌─────────┐ ┌─────────┐   │
│   │我是家长 │ │我是孩子 │   │
│   └─────────┘ └─────────┘   │
│                             │
└─────────────────────────────┘
```

**功能：**
- 两个大按钮，点击跳转到对应登录页
- "我是家长" → `/parent/login`（蓝色风格）
- "我是孩子" → `/child/login`（橙色风格）

---

## 4. 家长端登录页

**参考原型：** `docs/prototypes/parent-login.html`

**功能：**
- 登录模式：用户名 + 密码登录
- 注册模式：用户名 + 密码 + 确认密码
- 登录/注册可切换

**注册后行为：**
- 自动创建新家庭
- 成为该家庭的创始家长
- 自动登录并跳转到 `/parent`

**视觉风格：**
- 主题色：蓝色 `#5B7FFF`
- 副标题："家长端管理平台"
- 底部提示："注册后自动创建家庭，成为创始家长"

---

## 5. 孩子端登录页

**参考原型：** `docs/prototypes/child-login.html`

**功能：**
- 仅登录：用户名 + 密码
- **无注册功能**（孩子账号由家长创建）

**登录后行为：**
- 跳转到 `/child`（任务页）

**视觉风格：**
- 主题色：橙色 `#FF6B35`
- 副标题："孩子端登录"
- 激励标语："完成任务，赚取积分，兑换心仪礼物！"

## 7. 登录逻辑调整

**当前逻辑：**
- `/login` → 统一登录 → 根据角色跳转到 `/parent` 或 `/child`

**新逻辑：**
- `/parent/login` → 家长登录 → 跳转到 `/parent`
- `/child/login` → 孩子登录 → 跳转到 `/child`
- `/` → 首页入口 → 选择后跳转到对应登录页

**Middleware 调整：**
- `/parent/login` 和 `/child/login` 为公开路由
- `/parent/*`（排除 `/parent/login`）需 PARENT 角色
- `/child/*`（排除 `/child/login`）需 CHILD 角色

---

## 8. API 无需调整

登录 API `/api/auth/login` 和注册 API `/api/auth/register` 保持不变。
