# 技术栈说明

本文档详细说明项目使用的各项技术及其在项目中的具体用途。

## 核心框架

### Next.js 16 (App Router)

- **用途**：全栈框架，同时提供前端页面渲染和后端 API 路由
- **配置**：部署到 EdgeOne Pages，支持 SSR 和 API 路由
- **路由模式**：App Router，所有页面和 API 均在 `src/app/` 目录下组织
- **渲染策略**：主页面 `page.tsx` 使用 `'use client'` 客户端渲染，API 路由在服务端运行
- **字体**：使用 `next/font/google` 加载 Geist 和 Geist Mono 字体，优化加载性能

### React 19

- **用途**：UI 构建库
- **状态管理**：主要使用 `useState` / `useEffect` 等 Hooks，复杂状态使用 Zustand

### TypeScript 5

- **用途**：类型安全的 JavaScript 超集
- **配置**：`strict: true` 开启严格模式，`noImplicitAny: false` 允许隐式 any
- **路径别名**：`@/*` 映射到 `./src/*`，简化模块导入
- **模块解析**：`moduleResolution: "bundler"` 适配现代打包工具

## 样式方案

### Tailwind CSS 4

- **用途**：原子化 CSS 框架，通过类名组合实现样式
- **集成方式**：通过 `@tailwindcss/postcss` 插件与 PostCSS 集成
- **动画**：使用 `tailwindcss-animate` 和 `tw-animate-css` 提供过渡动画
- **工具函数**：`cn()` 函数（`clsx` + `tailwind-merge`）用于条件类名合并，避免 Tailwind 类冲突

### shadcn/ui (New York 风格)

- **用途**：基于 Radix UI 的可定制组件库
- **风格**：New York 风格，更紧凑的间距和更小的圆角
- **图标**：Lucide React
- **组件位置**：`src/components/ui/`
- **配置**：`components.json` 定义组件别名和样式变量
- **底层依赖**：每个组件基于 `@radix-ui/react-*` 原语构建，确保无障碍访问

## 数据层

### Prisma

- **用途**：TypeScript ORM，提供类型安全的数据库访问
- **数据库**：生产环境使用 Turso (libSQL)，本地开发使用 SQLite
- **Driver Adapter**：通过 `@prisma/adapter-libsql` 适配 Turso 的 HTTP 连接
- **自动切换**：当配置了 `TURSO_DATABASE_URL` 和 `TURSO_AUTH_TOKEN` 时自动使用 Turso，否则使用本地 SQLite
- **客户端模式**：开发环境使用全局单例避免热重载时创建多个连接
- **Schema 位置**：`prisma/schema.prisma`
- **ID 策略**：使用 CUID 作为主键
- **迁移方式**：本地使用 `prisma migrate dev` 生成 SQL，通过 Turso CLI 应用到远程数据库

### Turso (libSQL)

- **用途**：边缘分布式数据库，基于 libSQL（SQLite 分支），通过 HTTP 连接
- **优势**：全球分布式低延迟、自动备份、与 SQLite 100% 兼容
- **本地开发**：使用本地 SQLite 文件（`dev.db`），无需 Turso 连接
- **生产连接**：`libsql://db-name-org.turso.io`，通过 Auth Token 认证

## 表单与验证

### React Hook Form

- **用途**：高性能表单状态管理，减少不必要的重渲染
- **验证集成**：通过 `@hookform/resolvers` 桥接 Zod schema 验证

### Zod

- **用途**：TypeScript 优先的 schema 验证库
- **使用场景**：API 请求参数验证、表单输入验证

## 状态管理

### Zustand

- **用途**：轻量级全局状态管理库
- **使用场景**：跨组件共享的复杂状态

### React Hooks

- **用途**：组件内局部状态管理
- **使用场景**：页面级状态、UI 交互状态

## 数据请求

### TanStack React Query

- **用途**：服务端状态管理，提供数据缓存、自动重请求等能力
- **使用场景**：API 数据的获取、缓存和同步

## 认证

### 自定义 Cookie 认证

- **用途**：基于 Cookie 的会话管理
- **密码加密**：`bcryptjs` 对用户密码进行哈希加密存储
- **流程**：登录 → 验证密码 → 设置 Cookie → 后续请求通过 Cookie 识别用户

## 图标与视觉

### Lucide React

- **用途**：SVG 图标库，提供一致的图标风格
- **使用方式**：按需导入，Tree-shaking 友好

### Framer Motion

- **用途**：React 动画库，提供声明式动画 API
- **使用场景**：页面过渡、组件交互动画

## 图表

### Recharts

- **用途**：基于 React 和 D3 的图表库
- **使用场景**：数据可视化展示

## 日期处理

### date-fns

- **用途**：轻量级日期工具库，提供函数式 API
- **使用场景**：时间计算、格式化、兑换日判断（所有时间基于北京时间 UTC+8）

## 开发工具

### ESLint

- **用途**：代码质量检查
- **配置**：使用 `eslint-config-next` 的 `core-web-vitals` 和 `typescript` 预设
- **配置文件**：`eslint.config.mjs`

### pnpm

- **用途**：包管理器，替代 npm/yarn
- **优势**：磁盘空间高效、严格的依赖隔离、安装速度快

## PWA 支持

项目配置了 PWA 相关元数据：

- `manifest.json` — Web 应用清单
- 多尺寸图标（192x192、512x512）
- Apple Touch Icon 和相关 meta 标签
- `theme-color` 和 `apple-mobile-web-app-capable` 配置

## 部署

### EdgeOne Pages

- **用途**：腾讯云边缘部署平台，支持 Next.js 全栈应用
- **支持特性**：App Router、SSR、ISR、Route Handlers
- **部署方式**：Git 仓库连接自动部署，或使用 EdgeOne CLI
- **全球加速**：基于腾讯云 3200+ 全球 CDN 节点

## 依赖关系概览

```
Next.js (App Router) → EdgeOne Pages (部署)
├── React 19
│   ├── shadcn/ui → Radix UI → Tailwind CSS 4
│   ├── React Hook Form + Zod (表单验证)
│   ├── Zustand (全局状态)
│   ├── TanStack React Query (数据请求)
│   ├── Recharts (图表)
│   └── Framer Motion (动画)
├── Prisma → @prisma/adapter-libsql → Turso (数据层)
├── bcryptjs (密码加密)
├── date-fns (日期处理)
├── Lucide React (图标)
└── Sonner (Toast 通知)
```
