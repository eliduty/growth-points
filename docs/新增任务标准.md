# 新增任务标准（参照手册）

> 配套《积分规则-优化方案 v3》使用。后期新增任务 / 心愿时按本手册执行，保证规则体系一致、不随拍脑袋漂移。

---

## 一、准入判断（先过三关，任何一关不过就不加）

1. **目的关**：这项任务服务于三目的之一吗？（养成习惯 / 支持成绩 / 传递"哪些事是对的"）
2. **重复关**：现有任务已覆盖的能力不重复上架；同类不同教材可并存作为菜单选项（如学霸 / 举一反三），但须各自有独立验收物。
3. **可验收关**：能用一句话说清"怎么算完成"吗？说不清就不加，先把标准想出来。

## 二、归分类（决定它出现在哪里）

| 任务特征 | 归入 | 位置 |
| --- | --- | --- |
| 每天必须做的底线行为（不做有真实后果） | 每日必做 | 置顶分类 |
| 课外拓展，做了更好，不做无后果 | 自选任务 | 菜单 |
| 低频结果性事件（考试、奖状、老师公布） | 学习成绩 | 事件发生时记录 |
| 品行类（礼貌、诚实、助人） | **不进积分系统** | 用口头肯定，见红线 2 |

## 三、定类型（决定验收方式）

| 类型 | 特征 | 验收方式 |
| --- | --- | --- |
| 动手类（输出） | 做题、写字、家务，有可见成果 | 自证明：答案 / 成果可见即可，无需额外验收 |
| 输入类（看/听/读） | 只看时长可挂机摸鱼 | **必须配轻验收**：复述一句内容、跟读一段、随口一问 |
| 事件类 | 低频结果 | 家长确认事件真实发生 |

## 四、定价（对照标定样本就近取档）

**总原则：分值不重新推导，对照现行同类样本就近取档；新任务宁低勿高**——降分是"降价"，孩子会觉得越努力越吃亏；上调是惊喜，永远留有余地。

**标定样本表（现行 v3）：**

| 档位 | 样本 | 适用场景 |
| --- | --- | --- |
| 2 分档（小事底线） | 起床、睡觉、整理书包、打扫卫生 | 每日必做的小事 |
| 10 分档（核心底线） | 按时完成作业（21:30 前）、周六前完成周末作业 | 当天最重要的一件事 |
| 输入类时长阶梯 | ≤10 分钟 = 2；20 分钟 = 4；30 分钟 = 6 | 看 / 听 / 读类 |
| 动手课外档 | 口算 1 页 = 3；思维题 3 道 = 3；举一反三 3 道 = 3；英语阅读 1 篇 = 2 | 课外题组（2~3 分） |
| 过程 + 质量双档 | 口算完成 3 + 全对 3；作业完成 10 + A+ 3 | 质量可客观判定的动手任务 |
| 事件中小额 | 学校作业 A+ = 3；排名三/二/一 = 2/3/5 | 老师反馈类 |
| 事件大额（低频） | 考试 90~94 = 10；考试 95+ = 30；奖状 = 10 | 学期低频大事件 |

**新任务定价流程**：找同类最近样本 → 就近取档 → 质量可判定则拆"完成 + 做好"两档 → 首月为观察期，分值不动。

## 五、写标准（任务描述怎么写）

- 写**时间节点**：如"21:30 前""睡前"
- 写**可验证动作**：如"晚饭后收拾碗筷 + 扫客厅地面"，而非"打扫卫生"
- 输入类附**验收句**：如"读后用一两句话说说今天读了什么"
- 一句话说清，**孩子能背下来**

## 六、频次设置

- 每天可做：不设 `availableDays`
- 固定星期几做：设置 `availableDays`（系统已支持）
- 同一任务每天限完成 1 次（系统默认）；周任务（如周末作业）单列一条，不与每日任务混用

## 七、退出（毕业）

- **只能庆祝式毕业**（"这个习惯你已经养成了，全家庆祝一下，它不用再挣分了"），**严禁降价式退出**（v3 铁律）
- 任务上线先跑 3~4 周观察期，用实际完成数据决定去留，不凭感觉调

## 八、红线（禁止项）

1. **不设罚分**：只奖不罚，纠错用家长"撤销"功能
2. **品德行为不计价**：礼貌、诚实、帮助他人用口头肯定，付钱会腐蚀善意（过度合理化效应）
3. **不奖励纯攀比结果**：相对位次类只保留现有"老师定期公布排名"一条，不新增
4. **输入类不得只写"看 / 听 X 分钟"**：无验收标准的输入类任务不予上架
5. **屏幕时间只能出现在礼物侧**：不能成为任务（任务是挣分项，屏幕是消费项）
6. **孩子本来就沉迷热爱的事谨慎计酬**：对已有内在兴趣的活动付积分会削弱兴趣；积分优先用于"需要推动的冷启动"行为

---

## 附：心愿 / 礼物定价参照

- 现金：5 分 = 1 元，`weeklyLimit` = 每周 20 元（零花钱通道）
- 游戏：30 分 = 周末整块 30 分钟，`weeklyLimit` = 每周 3 次（90 分钟/周）
- 心愿清单：孩子提案 → 家长审核定价上架；定价梯度参照 **50 分（约一周攒分）/ 100 分（约两周）/ 200 分（约一月）** 三档，新心愿按内容就近入档
