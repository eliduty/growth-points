# 积分规则优化方案 v3（评审定稿）

> 基于《积分规则.md》（线上现行规则 v1）的优化整理。
> 来源：2026-09 规则评审讨论。
> 基准原则：**v1 分值是已在线上验证过的锚，不轻动**；优化集中在结构、标准、礼物与机制，不靠推导改价。
> 目标不变：习惯养成 + 成绩提升 + 让孩子一眼看到"哪些事是对的"。

---

## 设计原则（本次优化的底层逻辑）

1. **菜单制**：任务不要求全完成，做多少拿多少，尊重孩子自主权。
2. **必做 / 自选分组**：底线项置顶为"每日必做"，课外拓展为"自选任务"。不强制，靠位置引导（默认选项效应）。
3. **分值以 v1 为锚**：现有任务分值不动，避免在未经观察的推导上反复调价；后续调整以实际运行观察为准。
4. **动手类与看/听/读类差异化在"标准"而非"价签"**：动手类（口算、思维题等）天然自证明——做得出来就是做出来了；看/听/读类是输入型，只看时长可挂机摸鱼，须加一道轻验收。
5. **奖励可控的行为，而非不可控的结果**：结果类奖励保留仪式感，但填平悬崖。

### 心愿清单机制（新增）

- **流程**：孩子自己提心愿（玩具 / 模型 / 卡牌 / 活动均可）→ 家长审核、定价、上架 → 孩子攒分兑换。
- **定位**：心愿清单是**主奖励通道**，现金降级为"零花钱通道"。
- **教育价值**：为孩子真正想要的东西攒大额积分，训练延迟满足与储蓄规划；目标梯度效应让孩子主动关注进度。
- **实现成本**：Gift 表为通用结构（名称/积分/描述），上架心愿仅是操作流程，**零代码改动**。
- 首批心愿条目：**家长拟定候选清单，孩子勾选**。候选需覆盖实物 / 体验 / 特权三种类型各若干项，避免孩子只盯一个档位；同时保留"孩子随时提案新心愿、家长审核定价上架"的口子。

## 三、长期机制约定：任务"毕业"原则（淡出）

- **背景**：积分是脚手架。习惯内化后外部奖励应逐步退出，避免孩子一辈子"为分做事"。
- **定案（沟通铁律）**：将来任何任务"退休"，**只能以庆祝形式呈现**（如"这个习惯你已经养成了，全家出去吃一顿庆祝毕业，它不用再挣分了"），**严禁以"降价 / 减分"形式呈现**——"做得越好分越少"会让孩子觉得越努力越吃亏。
- **时点**：本次不定。等观察期（3~4 周）数据，哪条习惯稳定、何时毕业，届时回顾决定。

## 五、未决事项（尚未讨论定案）

1. **周度目标激励**：菜单制下"全勤奖"不适用，可考虑"每周积分达到 X 分额外奖励"（可先用家长 Reward 手动发放，无需开发）。本次未定案。
2. **"完成外研U学记单词"**：v1 中无分值（系统创建任务必须填积分），需决定：补分值上架，还是放弃该条目。
3. **分值观察期**：动手/输入类差异与各任务分值，建议新标准运行 3~4 周后按孩子的实际完成数据回顾一次，不提前调价。
4. **展示层确认**：孩子端首页"每日必做"分类置顶后的视觉效果，上线前验收一次。
